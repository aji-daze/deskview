# DeskView

Android タブレットで WordPress 管理画面（`/wp-admin`）や Canva を「PCと同じデスクトップ表示」で使うための専用ブラウザアプリです。詳しい設計意図は [DESIGN.md](./DESIGN.md) を参照してください。

## 概要

- WebView にデスクトップ版 Chrome の User-Agent を設定し、モバイル簡易版に落とされずにブロックエディタや Canva の編集画面を使えるようにします。
- ハードウェアキーボード・Bluetooth マウスでの操作を前提にしています。
- 汎用ブラウザではなく、WordPress と Canva を快適に使うための最小構成のアプリです。

## 対応端末

- Android 8.0（API 26）以降
- RAM 4GB 以上を推奨（Canva の描画負荷のため、4GB未満の端末は動作対象外とします）
- Android System WebView が新しい端末を推奨します。起動時にバージョンを自動チェックし、古い場合は更新を促すダイアログを表示します。

## インストール手順

1. このリポジトリの GitHub Actions（Actions タブ）から最新のビルドを開き、Artifacts の `deskview-debug-apk` をダウンロードします。
2. タブレット側で「提供元不明のアプリ」のインストールを許可します。
3. ダウンロードした APK をタブレットに転送し、タップしてインストールします。
4. アプリを起動し、メニュー（⋮）→「設定」から自分の WordPress 管理画面の URL を入力します。

※ Play Store 配布は行っていません（GitHub Releases / Actions Artifacts での配布を前提にしています）。

## WordPress 管理画面 URL の設定方法

1. アプリを起動し、右上の「⋮」メニューを開きます。
2. 「設定」を選び、`https://example.com/wp-admin/` のように自分のサイトの管理画面 URL を入力して OK を押します。
3. 保存後、新規タブや初回起動時のブックマークに反映されます。

## ログインに関する注意（重要）

Google はセキュリティ上の理由で、埋め込み WebView からの Google ログイン（OAuth）を `disallowed_useragent` エラーで拒否することがあります。DeskView はデスクトップ版 Chrome を名乗る User-Agent を使うことでほとんどの場合は通りますが、**保証はありません**。

- **Canva**: Google ログインが拒否された場合は、**メールアドレス＋パスワードでのログイン**を利用してください。
- **WordPress**: 通常は自前の認証（ユーザー名・パスワード）のため、この問題の影響はほとんどありません。

Cookie は端末内に保存され、再起動後もログイン状態を維持します（メニューからログアウトしない限り再ログインは不要です）。

## インストールできないとき

### 「既存のパッケージと競合するためインストールできません」

同じ `dev.deskview` が別の署名鍵で入っているときに出ます。**一度アンインストールしてから、新しい APK を入れ直してください。** ブックマークとログイン状態は消えます。

この作業が必要なのは、固定の署名鍵を導入する前にインストールした APK を使っている場合だけです。固定鍵の導入後にビルドされた APK どうしなら、アンインストールなしで上書き更新できます。

### 署名鍵について

`keystore/deskview-debug.jks` は CI が初回に自動生成してリポジトリに commit した **debug 用の鍵** です。パスワードは `deskview` で、リポジトリ内に平文で置いてあります。

- 目的は、ビルドのたびに署名が変わって上書き更新できなくなるのを防ぐことです。
- 個人がサイドロードして使う前提の鍵です。**Google Play へ公開する場合は、この鍵を使わず別途 release 用の鍵を作ってください。**
- 公開リポジトリのままだと、第三者が同じ鍵で署名した APK を作れます。気になる場合はリポジトリを Private にしてください。

## ショートカット一覧（ハードウェアキーボード）

| キー | 動作 |
|---|---|
| `Ctrl` + `T` | 新規タブを開く |
| `Ctrl` + `W` | 現在のタブを閉じる（最後の1枚ならアプリを終了） |
| `Ctrl` + `L` | URL入力欄にフォーカス（全選択） |
| `Ctrl` + `R` | 現在のタブを再読み込み |
| `F11` | 全画面表示のオン/オフ切り替え |

その他の操作:
- 端末の戻るキー: WebView の履歴があれば戻る。履歴が無ければタブを閉じる（タブが1枚のみならアプリを終了）。
- タブを長押し: そのタブを閉じる。
- メニュー（⋮）: ブックマーク追加 / ブックマーク一覧 / 全画面 / ズーム(80–125%) / 外部ブラウザで開く / 設定。

## ビルド方法（開発者向け）

Gradle Wrapper のバイナリ（`gradle-wrapper.jar`）はリポジトリに含めていません。ローカルでビルドする場合は、事前に Gradle 8.7 以降をインストールした上で以下を実行してください。

```bash
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
```

CI（`.github/workflows/build.yml`）では push のたびに同じ手順で debug APK を自動ビルドし、Actions の Artifacts に添付します。
